# API Reference

The complete **SPP API reference** — every file, function, struct and macro,
generated straight from the source comments with Doxygen.

[Open the API reference](/doxygen/){ .md-button .md-button--primary }

It is rebuilt from `solaris-v2/` and published alongside this site on every
deploy, so it always matches `main`.

To build it locally, from the repository root:

```bash
doxygen Doxyfile          # output in doc/html/
```
